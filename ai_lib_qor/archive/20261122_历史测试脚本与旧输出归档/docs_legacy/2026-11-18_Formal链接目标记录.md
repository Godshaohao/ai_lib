# Formal NL 软链接原始目标

`link_target` 是来源同步时用 `os.readlink()` 得到的原始链接文字；相对目标原样保存，不用最终绝对路径冒充。Formal 相对路径表示链接在 NL 内的位置；`raw_version` 与 `raw_path` 来自可唯一关联的已登记 Delivery。三者作用不同。

自动同步的新不可变快照为 `formal_snapshot.v2`，在每个已归库的链接条目中增加 `link_target`；它保留 v1 的其余字段和 `coverage`。Schema 在 `schemas/formal_snapshot_v2.schema.json`，旧 `formal_snapshot.v1` 仍按原 Schema 读取，历史不改写。若同一链接只改变原始文字、最终解析路径不变，仍生成新的快照；构建时再次核对原始链接文字与观察内容。相同链接集合和文字则复用先前快照。

同步观察记录也保存链接目标：断链仍保存其 `readlink` 文字，普通文件的 `link_target` 为 null，不假装它是链接。断链或无法唯一归属的链接保存在同步观察中，不能仅因为只有一个库就猜测归属；因此不一定进入某个库的正式快照。

共享读取与 `data-query --kind simple-formal` 输出 `formal.simple.v3`：已保存目标的字段原样输出；旧 v1 快照中没有目标文字时，`link_target=null`，`link_target_status=NOT_RECORDED`。查询不会读取当前 Formal 源目录来倒填历史值。对于中间层软链接或其他导致直接目标与最终路径不同的情况，额外输出 `resolved_path`；未匹配项仍保留已观察到的最终路径。

`schemas/formal_simple_v3.schema.json` 验证简化查询格式；该查询结果不是第二份权威快照。`compare_formal` 兼容 v1 / v2 / v3 简化结果；来源一致不代表文件内容一致。简化输出没有 `coverage` 不代表范围完整，完整性应查询原始快照；不能据此自动采纳。

本次示例在隔离工作目录中重新同步了本地公开样本，并逐条对比 `readlink()`：5 库快照、示例库 7 条链接均生成；示例库 7 条链接目标均为相对路径。原有 RAW / Formal 和历史快照未改写。可查看示例 [formal.simple.v3](../exports/formal_link_target_review_huos9l37/formal_NL2.5.3_001.simple.v3.json) 和对应 [formal_snapshot.v2](../exports/formal_link_target_review_huos9l37/work/libraries/SRAM22/sram22_256x16m8w8/formal_NL2.5.3_001.json)。
