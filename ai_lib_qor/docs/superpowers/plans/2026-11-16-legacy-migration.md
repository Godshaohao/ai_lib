# 旧版能力迁移实施计划

目标：将旧版检查能力与操作路径迁入新 v3 工作台，先保证证据可信和现有合同，再补齐自动化与用户交互。

用户是库工程师；判断是某个 IP、版本和选定文件的证据与差异。输入为只读 RAW、交付和正式快照及明确映射；输出为版本化检查记录、独立证据、HTML/Excel。不得修改来源、静默扩大覆盖或把未执行表示为 PASS。

1. 结果证据：验证 CheckResult 的明细、汇总与覆盖一致性；核验解析事实内容。为每个反例先写测试。
2. 富解析：复用旧版 LEF、Liberty、Verilog、CDL 解析；以独立、可追踪证据保存 v3 不支持的几何/PG/其他视图，不虚构 v3 FileFacts。覆盖不完整必须显式报告。
3. 插件与编排：定义固定范围贡献与可信插件注册；计划显式限定目标、事实和参数；一个 assembler 合并，结果发布前验证。未知项/重复身份/错误引用必须失败。
4. 工作台：从可靠交付与版本记录选择 IP、文件和检查；配对必须明确或可证明唯一；历史按 IP 和版本隔离；仅开放已实现的交互。
5. 报告：同一固定 run 和证据生成 HTML/Excel；逐项比对旧版，清楚区分未提供/未覆盖。使用真实 RAW 副本验证，不动真实来源。

各阶段需适当测试、异常用例和端到端验证；旧能力和源解析语义逐项对照，未实现项保留清单，不标为完成。
