# ADR-0003：路径式查询与旧历史迁移

日期：2026-11-21；状态：已实施，模拟及本地验收副本已验证。

在用户确定的精简 Delivery、Formal、Effective 与文件路径索引上，新 CLI、路径式工作台和检查流程使用共享 `PathDataQuery`；同库和单次检查的成员以已发布 Effective 为准。`path_sources.json` 为新配置，保留旧登记时间的过渡读取。Effective 的预览、父版本校验发布和历史组合恢复使用同库锁；排除策略不改写历史。权威文件不可变，索引可重建。

旧库向独立工作目录迁移时先利用旧引用解析来源，再写出路径式记录，不复制身份 sidecar；存在无法唯一映射的历史时停止。迁移不自动重建旧检查结果，也不证明归档正式链接的现场状态。当前仍保留旧代码与兼容入口，跨库业务 IP、增量扫描、插件统一编排不属于本次实现范围。
