# ai_lib src_qor · 项目设计知识地图

> 本地图从 `src_qor` 当前源码、测试与 README 汇总可追溯的工程结构，并把产品意图和待确认设计与实现事实分开。它不是 EDA 质量认证，也不替代 RAW、正式 NL、检查 Evidence 或 Excel 报告。

## 目的

帮助维护者回答：检查数据从哪里来、检查如何组合、结果如何传给操作者和 IP 阅读者、哪些结论仍受证据范围限制。

## 当前范围

- 本地图只描述独立的 `src_qor` 工具链：RAW 发现与登记、正式 NL 只读盘点、按 IP 执行检查、报告与工作台。
- 代码路径和测试是实现现状的依据；节点中的产品目标若未由代码或测试证明，标为“提议”或“待核实”。
- 原始库、正式发布目录和测试报告均留在原位置。本目录只保存设计知识及由它生成的离线 HTML。

## 阅读方式

从“数据工程”查看 RAW / 正式目录和检查输出；从“信息架构”查看操作者与阅读者的任务；从“信息设计”查看工作台和报告视图。选中节点可查看关系、状态和来源路径。

## 可信度边界

`status` 表示设计知识的确认状态；HTML 中单独显示的 freshness 是来源和复核状态。当前节点尚未经过项目负责人逐项确认，因此不得把提议节点当作正式决策。检查任务 `COMPLETE` 只说明所选检查执行结束，不代表库整体通过或允许发布。

## 当前待核实

- 对真实使用者进行任务观察，确认操作者和 IP 阅读者的首屏信息是否足以支持其决策。
- 为需要持续追踪的源码证据选择小型、稳定的摘要清单；本地图不对大型 LEF、Liberty、GDS 或报告做哈希。
- 核对各检查器的解析覆盖边界与项目实际交付约定，避免把“未检查”解释为“无问题”。
