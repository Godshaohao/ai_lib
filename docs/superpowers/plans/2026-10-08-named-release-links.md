# 正式目录发布与当天备份

目标：发布负责人可以指定正式目录名与最新指针名，默认覆盖链接。

目录约定：`<root>/<publish_name>/` 为正式文件树，`<root>/<latest_name>` 指向它。
覆盖前复制旧文件树，保留符号链接本身到 `history/<publish_name>_YYYYMMDD/`。
同一天再次发布覆盖当天备份，日期使用运行机器本地日期。

实施顺序：
1. 测试命名、同日覆盖、链接保留与失败回退。
2. 发布 manifest 与 linker 支持命名目录，沿用暂存、锁和校验。
3. CLI 与 Web 接入相同参数；发布别名仍用于门禁，不作为目录名。
4. 测试预演不写入、正常覆盖、错误源、校验失败与现有发布回归。

边界：不新增命令；不更改 scan/diff/effective；旧配置未指定正式目录名时保持原布局。
