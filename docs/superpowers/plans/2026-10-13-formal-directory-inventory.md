# 正式目录只读盘点

用户：正式库管理者。输入：正式目录路径和已登记版本路径。输出：工作区盘点快照、库/版本汇总与文件表。正式目录只读，不写链接、不切换有效版，不扫描 RAW 或计算内容哈希。临时发布记录独立展示。

- [x] 测试真实混合展平目录：多库、多版本、复制文件、失效链接、未知来源；不跟随目录链接递归。
- [x] 新增只读 inventory 模块，复用 canonical 类型映射和原子快照写入。
- [x] Web GET/刷新接口与正式目录表格、筛选、分页；与发布准备路径分离。
- [x] 全量回归、浏览器模拟盘点、截图和来源核对。

来源规则：链接目标落入已登记版本路径，最长路径优先；同等路径归属冲突不自动选。普通文件无来源证据时保持待确认。不读取内容推测 Corner，本轮明确显示“未记录”，没有读取完整扫描 JSON。

边界：只索引普通文件及文件链接；不跟随目录链接，界面报告未展开数量。盘点不修复断链、不发布、不切换有效库；工作区快照不是新的发布事实。复制文件无法自动确定来源，本轮不提供人工归属写入。
复杂度：按链接目标的祖先路径匹配来源，避免逐文件遍历所有版本；不计算内容哈希。文件分页 100 行；索引完整后原子替换，读取失败保留旧快照。

验收：790 项 unittest 通过（12.804 秒）；最终 UI/盘点专项 42 项通过。JS 语法、compileall、git diff --check 通过。日志 /tmp/formal_inventory_final.log。
浏览器：实际刷新模拟正式目录，识别 2 库、4 来源版本、20 文件（18 个正常链接、1 个断链、1 个复制文件），未知来源 2。已验证断链筛选、来源库筛选、临时记录切换、错误路径保留旧快照、重开恢复路径和快照；无控制台错误。截图 /tmp/ai_lib_formal_directory_20261013.png。
变更边界：新增 release/inventory.py；更新 Web API、模板、JS/CSS、教程和测试。未改变临时发布 linker、scan/parser、diff、有效库确认或 CLI。
