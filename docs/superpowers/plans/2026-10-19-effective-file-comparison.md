# 有效组合与文件对比修复计划

目标：每库保留唯一已确认当前有效组合、可查多个历史组合；在已有扫描事实中可靠配对文件，并允许从 Web 选择同类型文件做人工两两对比。

1. 锁定回归：多库当前指针互不影响、历史组合保留、包装目录变化下的唯一文件候选、无证据不报修改、Web 两侧路径校验。
2. 调整 scan diff：精确/逻辑路径优先；剩余文件按唯一同类型名称建立候选，大小不同仅在身份足够明确时报告修改；歧义保持增删和提示，不全量哈希。
3. 调整 Web：有效组合区明确展示当前与历史，文件对比可从版本扫描清单选旧/新路径；已有绝对路径专家入口保留。
4. 验证：定向 unittest、完整 unittest、compileall、JS 语法及浏览器操作；不自动提升原始最新版为当前有效版。
