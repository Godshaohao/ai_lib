# 源库与已发布目录切换

目标用户：库管理员。判断：哪个阶段正在交付、包含哪些库、文件链接到哪里。
输入：已登记源库、现有发布索引和实际发布 manifest。输出：双目录导航、只读交付核查表。
禁止扩展：不修改扫描、有效组合和发布算法；不增加数据库；切换不能触发发布或扫描。

1. 先测试读取已发布阶段文件：无源库也能查看、路径越界拒绝、分页和筛选、链接状态。
2. 提供只读阶段详情 API，从发布 manifest 而非当前 effective 读取。
3. 左侧增加源库/已发布切换，分别保存选择与筛选；阶段下展开组件库。
4. 已发布主区只展示交付事实和有界文件表；跳回源库为明确动作，更新按钮显式载入当前有效组合。
5. 全量回归及浏览器检查，确保浏览交付不改变链接或源库上下文。
