# 操作台信息减负

目标：减少重复状态和同时展开的设置，保留操作、证据和风险核查能力。

1. 顶部只固定当前对象和运行反馈；版本列表默认收起，保留搜索、筛选和完整历史。
2. 版本分析动作平级可见，一次只展开一种动作；保留既有命令与参数。
3. 备注摘要优先显示；删除重复内部标签和常驻原理说明。
4. 发布部分成功保留醒目状态、冲突表与目的路径；危险操作仍确认。
5. 自动化验证默认状态、动作切换、旧入口联动及全量回归；桌面浏览器验证。

不修改扫描、对比、有效版或发布算法，不删除事实数据，不新增依赖。

检查项：
- [x] 顶部版本列表可展开，筛选与历史入口保留。
- [x] 扫描、对比、深度对比、审查只显示当前动作设置；切换保留输入。
- [x] 进入审查的旧入口可自动打开对应动作。
- [x] 备注与文件核查入口可见，未删除任何操作。
- [x] 部分发布和冲突明细通过已有回归验证。
- [x] 756 项全量测试通过；桌面浏览器验证页签、键盘、版本表及审查入口。

验证样例：openroad_asap7 / 20260627_asap7，读取既有 205 个扫描文件，未重扫或发布。

已修正无基准的首版误显示“已有对比”；执行条件不变。

边界：本次减少展示冗余，不新增工程风险推断。详情页语义建议与证据可信度算法仍使用原有模型，旧静态 HTML 需要重新渲染才能呈现文案修改。

## 成熟软件组件对照

参考的是组件组织与交互约定，不是引入整套外部组件库：
- Carbon Data Table：工具栏集中搜索与筛选，采用 40px 表格行基准，允许多行内容自然增高。
  https://www.carbondesignsystem.com/building-blocks/core/components/data-table/guidelines
- PatternFly Tabs：区分工作区导航与当前页面操作页签，避免把主导航拉成同等大小的卡片。
  https://www.patternfly.org/components/tabs/design-guidelines/
- WAI-ARIA Tabs：已有页签保留选中状态、面板关联和键盘切换。
  https://www.w3.org/WAI/ARIA/apg/patterns/tabs/

落地：32px 控件基准、4/8/16 间距变量、13px 当前对象信息、状态自然换行；移除嵌套操作卡片边框和备注编辑的装饰色。
实测：表头 40px，搜索控件约 33px，当前对象字号 13px；全部历史筛选与操作页签可用。
验证：757 项测试通过；截图 /tmp/ai_lib_mature_components_20261012.png。
未变更：业务 API、扫描、对比、发布和人工审查规则。未新增依赖、字体下载或外部运行时资源。
