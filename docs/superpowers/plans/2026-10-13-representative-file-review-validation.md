## 可简化抽取的信息

| 类型 | 详情页值得保留 | 不应搬入主页面 |
| --- | --- | --- |
| LEF | 所选 macro/pin/尺寸/方向/层的变化定位 | 全部几何矩形、完整解析 JSON |
| Liberty | 已解析 cell/pin/面积/工艺条件变化 | 完整时序表；未解析字段不能声称已检查 |
| Verilog | module/port/方向/位宽，轻量解析限制 | 实例连接、参数展开和 HDL 语义通过结论 |
| CDL | subckt/pin/器件与实例变化 | 完整网表、电气或 LVS 通过结论 |
| SDC、UPF、CPF | 已解析约束/电源意图变化和定位 | 全部命令原文，工具有效性通过结论 |
| SPEF | 已提取头信息、网络数量等结构事实 | 完整寄生网络与未经验证的时序影响 |
| DB、GDS、OAS、NDM | 所选文件内容指纹/元数据差异及证据等级 | 二进制语义安全结论 |

本轮仅自动抽取小摘要、变化计数、最多六条定位及已有解析范围；上表不是新增各类型专用规则。
这些结果描述所选文件，不覆盖整个视图，也不替代原有版本 diff。

## 未验收与限制

- 真实浏览器全链路只验证 LEF；Liberty/Verilog/CDL 使用小型样例测试，不冒称生产库全类型通过。
- 未验证内网大型库和所有文件系统；保存复制既有报告，成本与所选报告体积有关，不读取全库原始内容。
- 当前 ASAP7 旧版本总体 diff 有大量未匹配文件；本轮不改写旧对比事实，不把代表文件一致升级为全库一致。
- 新鲜度按文件大小和修改时间提示，不是再次 hash；静态页面反映生成时状态。
- 未实现跨视图 pin/corner 一致性、HDL elaboration 或 signoff。
