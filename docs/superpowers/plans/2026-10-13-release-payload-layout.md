# IP 发布链接目录与文件选择

Status: current

## 目的与边界

目标用户：发布库维护者。判断：哪些源文件实际进入交付目录。
输入：已有 RAW、有效组合或发布清单。输出：链接计划、实际链接、排除原因。
不扩展扫描器、解析器、有效版推断、发布门禁和命令入口。

## 已确认规则

- Verilog/SystemVerilog 输出到 VERILOG；SPICE 输出到 SPICE；CDL 保留 CDL。
- 保留 LEF/GDS/LIB/DB，以及明确目录指定的 DFT/PGV/NDM/NDM_wo_lib。
- 每个视图目录展平，保留原文件名；只创建有交付文件的目录。
- 默认排除 README、文档、日志、备份和未明确归类的文件。
- 扫描证据不删除；发布文档检查不改变。
- 同名冲突全部跳过，其余继续；保留现有部分发布状态。
- 排除文件单独记录，不作为冲突或发布失败；全无可交付文件不得成功发布。
- 不自动迁移或删除已存在的历史发布目录。

## 实施与验收

1. 增加真实软链接测试，覆盖路径、名称与证据排除。
2. 收敛 release view 映射与统一发布选择函数，预演和执行共用。
3. 发布结果及 Web 展示排除数量、绝对源路径与原因。
4. 更新旧 RTL 输出断言；执行全量 unittest、compileall、JS 语法检查。
5. 核对多库同名冲突、显式清单和覆盖发布回归。
