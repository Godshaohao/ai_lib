# 发布结果的信息验收

目标用户：核对交付目录和文件来源的库管理员。
核心判断：是否实际发布，交付对象是否正确，覆盖范围和旧链接备份是否可核查。
输入：CLI 发布结果、链接清单和发布校验；不重新扫描，不生成第二套门禁。
输出：结论摘要、异常提醒、文件核查表；原始证据保留。

## 信息金字塔

- [x] 第一层明确区分预演、实际成功、失败与未校验，不混用“检查通过”和“已发布”。
- [x] 第一层显示库/版本、正式发布位置、最新入口、旧链接备份；路径可复制。
- [x] 第二层只展示异常、提醒以及新建/替换/指向相同的链接影响。
- [x] 数量可以下钻到具体文件；缺失数据不伪装为零或通过。
- [x] 第三层按视图类型、链接操作、异常和路径筛选，默认优先替换及异常。
- [x] 核查表展示发布文件、来源库/版本、旧指向、本次源文件与检查结果。
- [x] 表格固定表头、限定高度、分页；大量文件不能撑长整页。
- [x] 导出当前筛选结果，包含完整路径；单元格安全转义。
- [x] 完整命令和 JSON 入口下沉，不默认展开终端输出。
- [x] 链接指向相同不等于文件内容相同；失败回退不声称交付成功。

验证：模型缺失/失败/成功测试、前端筛选与摘要行为测试、桌面浏览器真实预演和筛选、相关回归。

- 自动测试覆盖成功/失败摘要、缺失数量、来源投影、筛选、CSV 转义及实际覆盖的旧指向；相关回归 206 项通过。
- 桌面浏览器使用 ASAP7 真实文件样例：预演 205 文件；默认只看替换及异常；切换全部后每页 50 行，共 5 页，已验证第二页。

- 本轮浏览器只做预演，不替用户执行实际发布；实际链接覆盖、同日备份覆盖及校验失败回退由隔离自动测试覆盖。
- 不评估移动端；本轮不宣称扫描、对比等所有页面都已完成信息精简。

## 发布展平规则修正（2026-10-09）

- [x] 单库、快照、有效组合和多库共同使用类型目录 / 文件名，不保留容量子目录。
- [x] 发布链接与清单严格保留来源文件原名、大小写和扩展名；旧目标名不能添加或删除容量字样。
- [x] 预演、实际链接、安装清单和后校验使用一致的展平路径。
- [x] 2kb、4kb、6kb、8kb 四个不同名文件真实链接创建与校验通过。
- [x] 展平后同名的不同源文件不静默覆盖，不产生成功交付目录。
- [x] 旧嵌套交付更新后新目录展平；日期备份仍保留旧嵌套链接，最新指针有效。
