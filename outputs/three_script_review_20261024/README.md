# 三类 IP 库检查结果

本结果包将三份已有检查报告整理为读者摘要和 Excel 明细。原始脚本输出及 JSON 证据未改写。

## 结论速读

| 检查 | 本次结果 | 阅读时应注意 |
|---|---|---|
| 正式 NL 目录 | 最高编号目录为 `lib_NL2.10_0`，相对 `lib_NL2.9_0` 有 2 条新增链接、5 条来源路径更新、无删除 | 只比较链接和解析后的来源路径，不读取文件内容；编号最高不等于当前有效指针 |
| LEF 双文件 | 212 个 Macro、1326 个 Pin；两文件 SHA-256 相同，未发现对象差异 | 结论只覆盖指定的这一对 LEF |
| LEF–Liberty | TT/SS/FF 各 1 个 Liberty；每文件与 LEF 同名 Cell 为 56/212；648 个信号 Pin、336 个电源/地 Pin 对照均无差异 | 每个 Corner 独立核查；156 个 LEF-only 名称表示单文件覆盖范围差，不直接等同交付缺失 |

## 对原报告的可读性检查

- 正式 NL 原报告的统计口径、版本排序、来源变化和限制说明交错。摘要版先给目录变化和 Corner/LIB-DB 配对，再保留路径变化不代表内容变化的边界。
- LEF 原报告的主体统计和结论清楚；逐 Macro 附录很长，适合在表格中筛选，而不应占据阅读摘要。
- LEF–Liberty 原报告重复列出三份相同的 156 个名称差异。摘要版合并共同结论，Excel 保留每个 Corner 的独立行，避免跨 Corner 合并事实。
- 先前的 Excel 版本只保留摘要表，确实没有把所有问题逐项问答，也没有完整展开对象明细；当前工作簿已经补入问答清单和可筛选的逐对象数据页。

## 范围

正式 NL 样例来自受控测试目录；结果可用于验证报告口径和展示，不代表生产正式库已通过验收。三个检查都不是正式发布放行结论。
